# Frontend

React + TypeScript frontend for the Supply Chain Control Tower.

## Planned Screens

- Control Tower Dashboard
- Document Upload Console
- OCR Extraction Review
- Validation Queue
- Inventory Balances
- Inventory Movements
- Shipment Tracker
- ERP Upload Generator
- Master Data Admin
- User and Role Admin

## Local Run

Once dependencies are installed:

```powershell
npm install
npm run dev
```
